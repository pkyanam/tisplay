Start here

Ask the installed CLI

Run these on the machine that has tisplay installed. Use the help output for exact options in that release.

tisplay --help
tisplay capabilities
tisplay session list

Use SSH for remote access. Commands execute through the SSH session and do not require opening a tisplay network port.

tisplay --host alice@workstation capabilities
tisplay --host alice@workstation session list

Lifecycle

Keep targets explicit

Start or select a session, retain its returned ID, pass that ID to later operations, then stop the session. This prevents accidental use of the wrong desktop when more than one session exists.

Use read-only discovery and capture before sending input. Add a human approval step for changes that matter.

Platform boundaries

Know the display

Linux uses accessible X11 or a private Xvfb/XFCE desktop. Direct Wayland capture is unsupported. macOS requires a logged-in desktop and Screen Recording and Accessibility permissions; it has no virtual mode.

Check tisplay capabilities for the installed version's current operation support and limits.
