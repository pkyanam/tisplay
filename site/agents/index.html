tisplay / agents

Agent quickstart

Start a session, inspect the screen, take one action, then inspect again. Use the installed CLI help and capability report for the target machine.

Start and inspect

tisplay capabilities --json
tisplay session start --json
tisplay screenshot --session SESSION_ID --out screen.png --json

Act and inspect again

tisplay click --session SESSION_ID --x 640 --y 360 --json
tisplay text --session SESSION_ID 'hello' --json
tisplay key --session SESSION_ID CTRL+L --json
tisplay screenshot --session SESSION_ID --out after.png --json

Use fresh screenshot coordinates in primary-display pixels. For a remote machine, add --host user@computer to each command; commands use SSH and open no listener port.

Use tisplay attach --session SESSION_ID --view-only to watch without acquiring input control. Start a fresh session after an upgrade; existing attached viewers and older sessions keep running.

Display modes

Linux selects an available supported desktop. For sessions, --mode native-existing requires an existing native desktop, --mode native-headless may create an isolated labwc/D-Bus session, and --mode virtual starts Xvfb/XFCE. Check capabilities for the actual backend.

macOS uses the logged-in desktop and requires Screen Recording and Accessibility permissions.
