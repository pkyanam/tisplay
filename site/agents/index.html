TISPLAY / AGENT QUICKSTART 02 / 03

Observe.
Act.
Observe again.

Keep a session ID. Take a fresh screenshot before acting, then inspect the result. Ask the installed CLI what the target supports.

ONE SIMPLE LOOPSESSION 01
tisplay --help
tisplay capabilities --json
tisplay session start --json

# Use the returned session ID
tisplay screenshot --session ID --out screen.png --json
tisplay click --session ID --x 640 --y 360 --json
tisplay screenshot --session ID --out after.png --json

Coordinates are pixels in the primary display. For a remote machine, add --host user@computer to each command; transport uses SSH and opens no listener port.

DISPLAY MODES

Check before choosing.

Linux selects an available supported desktop. For a session, choose --mode native-existing, native-headless, or virtual. Explicit headless mode can create an isolated labwc/D-Bus session without changing the system desktop. Inspect capabilities on the target.

macOS uses the logged-in desktop and requires Screen Recording and Accessibility permissions.

SAFE WATCHING

Read without control.

tisplay attach --session ID --view-only watches a live session without acquiring input control. Stop sessions when finished.
