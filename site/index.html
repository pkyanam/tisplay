tisplay

See and control a computer's desktop from your terminal, locally or over SSH.

Install

Run this on the computer whose desktop you want to access:

curl -fsSL https://github.com/pkyanam/tisplay/raw/refs/heads/main/install.sh | bash

The default Linux profile installs the virtual Xvfb/XFCE desktop. For native Wayland tools on Linux:

curl -fsSL https://github.com/pkyanam/tisplay/raw/refs/heads/main/install.sh | bash -s -- --profile native

Use

Open the local desktop:

tisplay

Or connect to a remote computer over SSH:

ssh -t user@computer '~/.local/bin/tisplay'

The SSH session carries the stream and input. tisplay does not open a network port.

Linux display modes

tisplay selects an available supported desktop. For a session, use --mode native-existing, --mode native-headless, or --mode virtual. Explicit native-headless mode may create an isolated labwc/D-Bus session. --virtual starts a private Xvfb/XFCE desktop.

Native Wayland support depends on the installed tools and active compositor. Check tisplay capabilities --json on the target machine.
