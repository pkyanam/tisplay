01 — Displays

Use what is there.

Linux selects an available supported desktop. Native Wayland depends on its compositor and tools; explicit headless mode can create an isolated labwc session. macOS uses the logged-in desktop with Screen Recording and Accessibility permissions.

02 — For automation

Observe, act, observe.

Use the installed CLI and its capability report to discover what the target supports. Keep a session ID, take a fresh screenshot before choosing an action, then inspect the result.
