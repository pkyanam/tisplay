Made for the terminal

A real desktop, where you already work.

Use your terminal's Kitty graphics support for full-color frames, or let tisplay draw through a compatible ANSI true-color renderer. Click, scroll, and type in the stream. Ctrl + ] closes a session.

Three ways in

Choose a session

Build a safe copyable command. The host field accepts an SSH destination such as alice@workstation.

Use the desktop you are logged into

Run the command in a terminal on the computer whose screen you want to see.

Stream a remote machine over SSH

SSH carries the image and input stream. Keep -t so the remote app gets a terminal.

First, install on the machine you want to access

Linux installs Python, X11/Xvfb and XFCE dependencies; macOS requires Python 3.10+ and a logged-in desktop.

curl -fsSL https://github.com/pkyanam/tisplay/raw/refs/heads/main/install.sh | bash

The installer uses sudo on Linux to add system dependencies, then installs tisplay in your user data directory. Read install.sh before running if you prefer to inspect it first.

Where it works

Platform notes

  • Linux · X11Captures an accessible desktop. Without one, starts a private Xvfb + XFCE desktop.
  • Linux · WaylandDirect capture is not supported. Use an X11 session or --virtual.
  • macOSUses the logged-in desktop; grant Screen Recording and Accessibility permission to your terminal or Python when prompted. No virtual display mode.

Picture in the prompt

Two renderers

Kitty Graphics Protocol shows full-color frames inline. Other terminals can use ANSI true-color half-blocks. Select one explicitly when auto-detection does not match your terminal.

tisplay --graphics ansi

Check the terminal path without accessing a desktop or sending input:

tisplay --test-pattern
