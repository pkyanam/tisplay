# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting for this repository](https://github.com/pkyanam/tisplay/security/advisories/new). Do not disclose an unpatched issue in a public issue or pull request.

Include the affected version or commit, the impact, and steps to reproduce when possible. Reports are reviewed by the maintainers; please allow time for assessment and a coordinated fix before public disclosure. No response or remediation deadline is guaranteed.

## Scope

This policy covers the `tisplay` source code and its published releases. It does not cover vulnerabilities in third-party software, operating systems, terminals, or SSH implementations; report those to their respective maintainers.
